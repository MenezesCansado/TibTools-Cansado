# TibTools Cansado

Kit de ferramentas para o Tibiano, desenvolvido por **Menezes Cansado**.

> 🛠️ Utilitários desenvolvidos para melhorar e facilitar tarefas relacionadas ao Tibia.

---

## 📦 Sobre o projeto

O **TibTools Cansado** é um conjunto de ferramentas desenvolvido para auxiliar jogadores de Tibia em tarefas relacionadas ao jogo.

O projeto está sendo desenvolvido de forma incremental, com novas ferramentas planejadas para futuras versões.

---

## 🛠️ Ferramentas

### 🗺️ Atualizador Cansado de Mini Mapa

Ferramenta para facilitar a atualização do minimapa do Tibia utilizando os arquivos disponibilizados pelo TibiaMaps.io.

**Recursos:**

- Atualização de Mapa sem perder as marcações pessoais
- Atualização automática
- Atualização manual através de arquivo `.zip`
- Backup do minimapa atual
- Restauração de backups
- Gerenciamento dos marcadores do minimapa
- Verificação da versão/data disponível

---

## 🙏 Créditos

O sistema de atualização de mapas do **TibTools Cansado** utiliza dados de mapas disponibilizados pelo projeto **TibiaMaps.io**.

Agradecimentos aos desenvolvedores e colaboradores do projeto TibiaMaps pelo trabalho de exploração, organização e disponibilização dos dados de mapas para a comunidade.

## 📥 Instalação

O TibTools Cansado é distribuído como aplicativo para Windows.

### Instalação

1. Acesse a página de [Releases](https://github.com/MenezesCansado/TibTools-Cansado/releases).
2. Baixe o instalador ou executável da versão desejada.
3. Execute o arquivo baixado.
4. Siga as instruções apresentadas pelo aplicativo.

> 💡 Recomenda-se utilizar sempre a versão mais recente disponível.

---

## 🔄 Atualizações

O TibTools Cansado possui sistema de verificação de atualizações.

Ao iniciar o aplicativo, ele pode verificar se existe uma versão mais recente disponível no GitHub.

Quando uma nova versão estiver disponível, o usuário poderá realizar a atualização diretamente pelo aplicativo.
